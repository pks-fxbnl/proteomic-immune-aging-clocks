# Demo code for proteomic immune aging model (LASSO + bootstrap ensemble)

## Summary

This package contains a fully runnable demo script designed to illustrate the workflow used in our manuscript for developing a proteomic immune aging (IMM-age) model based on 139 immune-related proteins.

To comply with journal data-sharing policies and protect participant privacy, the demo uses synthetic proteomics data with the same dimensional structure as the study datasets. The 139 protein names correspond to the immune-related features used in the study, while all simulated protein values and chronological ages are randomly generated. No real participant-level or biological measurements are included.

The code demonstrates:

1. Generation of synthetic proteomics datasets (training: n = 98 people without HIV; testing: n = 1,850 people with HIV).
2. Construction of a proteomic immune aging model using 139 immune-related proteins.
3. LASSO regression with five-fold cross-validation for lambda selection.
4. Ensemble prediction using a bootstrap-based lambda aggregation strategy (500 bootstrap models).
5. Generation of predicted proteomic immune ages for the training and test datasets.

**Note:** The synthetic protein values and ages are generated independently. Therefore, model performance and predictions obtained from this demonstration do not reproduce the results reported in the manuscript.

- R version 4.4.2

To install the required dependency:

```r
install.packages("glmnet")
```

## Running the demo

Open `immune_aging_demo_code.R` in R or RStudio and run the entire script.

The script will:

1. Generate synthetic proteomic datasets containing 139 immune-related protein features.
2. Generate synthetic chronological ages for 98 training and 1,850 test participants.
3. Train an IMM-age prediction model using bootstrap resampling and LASSO regression.
4. Select the optimal lambda through five-fold cross-validation within each bootstrap iteration.
5. Generate ensemble proteomic immune age predictions for the training and test datasets.

## Output objects

Once finished, the script returns the following R objects:

| Object | Description |
|---|---|
| `immune_age_demo` | Predicted proteomic immune ages for the 1,850 synthetic test participants. |
| `immune_age_train_demo` | Predicted proteomic immune ages for the 98 synthetic training participants. |
| `immune_res` | Complete model results, including lambda values, coefficients, loss metrics, and bootstrap predictions. |
| `immune_res$lambda_vec` | Optimal lambda selected in each of the 500 bootstrap iterations. |
| `immune_res$loss_table` | Cross-validation errors and bootstrap training R² values for individual iterations. |
| `immune_res$coefficients` | LASSO coefficients, including the intercept, from each bootstrap model. |
| `immune_res$train_pred_mat` | Training predictions from the 500 bootstrap models. |
| `immune_res$test_pred_mat` | Test predictions from the 500 full-training-data refitted models. |

## Data availability

All data generated by this demonstration are synthetic. No real participant information, clinical measurements, or protein abundance values from the 2000HIV project are included.

The script is intended to demonstrate the computational workflow rather than reproduce the manuscript's numerical results or provide a pretrained IMM-age model.
